# NBC_LGI_CH3_HW07

* 조작법
    * WASD: 이동
    * SpaceBar: 위로 이동
    * LShift: 아래로 이동
    * 마우스 이동: 시야(카메라) 
    * 마우스 휠: Zoom 조절

* Actor 이동
    * 이동은 Player가 보고 있는 방향으로 이동
    * 공중에 떠 있는 동안 중력 적용
    * 공중에 떠 있는 동안은 지상에 비해 50%의 속도로 이동
* Actor 회전
    * Actor는 회전 값 중 좌우만 반영
    * Camera는 회전 값 Yaw, Pitch 반영
    * Zoom
        * 마우스 휠로 SpringArmLength 조정
